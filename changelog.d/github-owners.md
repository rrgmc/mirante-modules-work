### Added

- The GitHub pull request, issue and CI health lists take several owners, separated by commas, such as "acme, acme-labs". The scope "One owner" is now "Owners". See [owners](github/README.md#owners).
- The scope "My organizations" in the GitHub pull request, issue and CI health lists covers every organization of the token's user. The list reads them from GitHub at each refresh, so it follows the organizations you join and leave.
